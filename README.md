# Mekanism Config Card Upgrades

Mekanism 配置卡扩展模组，支持配置卡对工厂配置与升级进行批量操作。

## 模组功能介绍

### 1. 增加了 `精准模式`、`模糊模式`、`清除模式`、`工厂模式` 四种工作模式

#### 精准模式

配置卡现在不只复制机器配置，还能复制和粘贴机器内的升级卡配置、工厂等级。  
粘贴时会按目标机器需求消耗对应升级卡；如果缺少材料，会提示 `粘贴失败，缺少XXX`。  
该模式下仅支持同类型机器。

#### 模糊模式

支持跨机器类型粘贴升级卡数据，只处理升级内容，不强求机器配置完全一致。  
模糊模式下遇到不兼容升级会跳过并提示，例如某机器不支持某类升级卡。

#### 清除模式

可将目标机器内的全部升级卡退回玩家背包，背包放不下时会中止并提示。  
支持一次框选多个方块区域，对多台机器批量执行粘贴或清除。  
批量逻辑可跨多种机器类型使用。

#### 工厂模式

可复制目标机器的工厂等级，并在粘贴时自动调用背包中的工厂安装器逐级升级。  
机器可以直接升级到对应等级。  
支持不同类型机器的工厂升级，不再局限于同一种工厂方块。

- 额外兼容了 `EvolvedMekanism`
- 额外兼容了 `Mekanism-Extras`
- 额外兼容了 `Mekanism-MoreMachine` 的工厂升级链

### 2. 新增了两个实用配方

- 任意 Mek 机器与配置卡一起合成，可将机器恢复为默认状态，并清除内部物品和升级数据，配置卡不消耗。
- 配置卡单独放入工作台合成，可清空卡内保存的数据。

### 3. 增加了工厂物品堆叠兼容

- 原版 Mekanism 工厂在“干净 NBT”状态下可堆叠。
- 额外兼容了 `Mekanism Extras` 与 `Mekanism MoreMachine` 的多种工厂物品，让重置后的工厂也能正常堆叠。

### 4. 兼容 FTB Ultimine 连锁模组

- 手持配置卡时，按住连锁键 + 左键，可对连锁到的机器执行批量粘贴、批量清除、批量工厂升级。
- 手持配置卡时，按住连锁键 + 右键，可对连锁到的机器批量执行原版配置卡右键逻辑。
- 未安装该模组时不会影响本模组运行。

### 5. 新增“卡槽包”

可用配置卡与 `8` 个高密度聚乙烯片在工作台合成。

- 执行配置卡复制粘贴操作时可直接调用卡槽包物品进行粘贴。
- 物品栏或 Curios 中含有卡槽包时，手持配置卡右键可打开卡槽包。
- 可佩戴在饰品 `belt` 栏中，可放置 Mek 升级卡与工厂等级安装器。
- 在 MEK 升级界面下方将直接显示卡槽包界面，可直接一键放入或移出该机器所支持的所有升级卡。

### 6. 手持配置卡对 MEK 机器鼠标中键可放入符合该机器所有升级卡

- 生存模式下将调用物品栏与卡槽包中的卡。
- 创造模式下无需卡且不消耗。

## 快捷键与使用方式

### 默认按键

- 键位分类：`MEK 配置卡扩展`
- 默认批量按键：`Ctrl`
- 可在游戏内按键设置界面修改为其他按键

### 快捷键如下

- `Shift + 右键机器`：保存升级数据
- `左键机器`：执行当前模式
- `Shift + 左键空气`：切换模式
- `Ctrl + 左键机器`：批量框选 / 批量执行
- `Ctrl + 左键空气`：清除当前批量选区
- `右键机器`：执行原版配置卡逻辑

### 配置卡怎么使用

1. 先按 Mekanism 原版方式对目标机器进行配置复制。
2. 复制后，配置卡除了原版配置外，还会额外保存：
   - 升级卡数据
   - 工厂等级数据（适用时）
3. 使用 `Shift + 左键空气` 切换到你需要的工作模式。
4. 对目标机器使用左键执行当前模式。
5. 如果要批量操作，按住批量键后依次左键两个方块，形成选区并执行。
6. 若需要快速补满升级卡，可手持配置卡对支持升级的 MEK 机器点击鼠标中键。
7. 若身上有卡槽包，手持配置卡右键即可直接打开卡槽包进行管理。

## 构建

```bash
gradle build
```

如果仓库中补充了 Gradle Wrapper，也可以使用：

```bash
./gradlew build
```

构建产物位于：

`build/libs/`

## 运行环境

- Minecraft: `1.20.1`
- Forge: `47+`
- Mekanism: `10.4.16+`
- Java: `17`
